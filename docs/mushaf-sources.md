# مصادر مصحف تبيان وتراخيصه

## ما الذي يُعرض؟
قارئ المصحف (`src/components/mushaf/`) يعرض صفحات المصحف **بخطوط متجهة (QCF v2)** — لا صور إطلاقاً:
كل صفحة من صفحات الطبعة المدنية (604) لها خط `woff2` خاص بها، وكل كلمة تُرسم كـ glyph متجه،
فيبقى النص حاداً تماماً عند أي تكبير، ولا تتغير أي حركة أو حرف أو ترتيب لأن التخطيط نفسه
(أي كلمة في أي سطر) محفوظ في البيانات.

## مصدرا البيانات والخطوط
| المورد | المصدر | المحتوى |
|---|---|---|
| خطوط الصفحات | `https://static.qurancdn.com/fonts/quran/hafs/v2/woff2/p{1..604}.woff2` | خطوط QCF v2 لرواية حفص — مجمع الملك فهد لطباعة المصحف الشريف |
| بيانات الكلمات والأسطر | `https://api.qurancdn.com/api/qdc/verses/by_page/{n}` | `code_v2` (رموز الحروف) و`line_v2` (رقم السطر) ورقم الآية/السورة/الجزء/الحزب |

هذه هي نفس البنية التي يعمل بها موقع quran.com الرسمي (Quran Foundation / QDC CDN).

## التنزيل والتخزين
- سكربت الإعداد لمرة واحدة: `node scripts/download-mushaf.mjs`
  - يخزّن 604 ملف JSON مدمجاً في `artifacts/tabyan/public/mushaf/pages/`
  - و604 خطاً في `artifacts/tabyan/public/mushaf/fonts/`
  - آمن لإعادة التشغيل ويتحقق نهائياً من سلامة كل الملفات (لا صفحة مفقودة/ناقصة).
- في وقت التشغيل لا يوجد **أي طلب API خارجي**: كل شيء يُقدَّم من ملفات التطبيق نفسه،
  ويُحمَّل كسولاً (الصفحة الحالية وجيرانها فقط) مع Cache API للعمل بكفاءة مع ضعف الشبكة.

## الترخيص والعزو
- خطوط مصحف مجمع الملك فهد (QCF): تُوزَّع عبر Quran Foundation لعرض نص المصحف كما هو دون تعديل؛
  الاستخدام هنا عرض فقط للنص القرآني كما ورد في الطبعة المدنية، بلا أي تعديل على الخطوط أو الرموز.
- بيانات QDC API: بيانات قرآنية عامة تابعة لـ Quran Foundation.
- البسملة ورؤوس السور تُعرض بخط Amiri Quran (OFL) — وهي خارج نص الآيات ولا تمسّها.

## دقة النص
- لا تُولَّد أي حرف برمجياً: كل glyph يأتي من `code_v2` الرسمي كما هو.
- ترتيب الأسطر مطابق للمصحف المطبوع عبر `line_v2` (يشمل أسطر رؤوس السور).
- لا يستخدم القارئ `transform: scale` على صورة؛ التكبير إعادة تصيير نص متجه — لا بكسلة ممكنة.
