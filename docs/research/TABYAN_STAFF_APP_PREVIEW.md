# TABYAN STAFF — معاينة ويب للمعلمين والمشرفين

## حالة التتبّع قبل التنفيذ

اكتمل هذا التتبّع قبل إنشاء واجهات المعاينة. أكّد المستخدم أن النطاق هو الواجهة فقط، من دون ربط أو اعتماد أي شيء للإنتاج. لا توجد تغييرات على تطبيق الطلاب أو ملفات المصادقة أو بيانات الموقع.

## حدود الربط التي كشفها التتبّع

- شاشات Native الحالية ليست قوالب معاينة مستقلة: تخطيط المعلم يفرض جلسة دخول ودوراً معتمداً ويطلب `teacher.kycStatus`؛ الصفحة الرئيسية تطلب `teacher.dashboard`. تخطيط المشرف يفرض جلسة مسؤول؛ صفحته الرئيسية تطلب `admin.kpis` و`admin.activeAdmins`.
- صفحات الويب بدورها تستعمل استعلامات tRPC وتغييرات خادمية. لذلك سيُعاد بناء عرض مستقل داخل Artifact جديد بدلاً من استيراد هذه الشاشات أو تشغيل وضع العرض التجريبي المرتبط بمخازن المصادقة/الخادم.
- لا يظهر في صفحات إدارة الويب المفحوصة مسار مستقل لإدارة صلاحيات تفصيلية. لذلك لن تُختلق صلاحيات تشغيلية أو تبديلات فعلية؛ شاشة الصلاحيات، إن عُرضت، ستكون وصفاً ثابتاً لأدوار المعاينة فقط.
- مفاهيم تسجيل التلاوات موجودة في `teacher/TeacherRecordings.tsx`؛ يمكن إظهار بطاقة تلاوة محلية في تفاصيل الطالب، من دون تشغيل أو رفع وسائط.
- واجهة التقييم في الويب تعرض درجات الحفظ الجديد والمراجعة والتجويد والأداء، وتوضح أن توصية المعلم لا تنفذ ترقية بحد ذاتها. ستبقى قواعد التقييم كما هي، ولن تُرسل نتيجة المعاينة.

## أساس الهوية المرئية

- لا يوجد Artifact من نوع design-system مسجل في مساحة العمل عند بدء التنفيذ؛ مصدر الهوية هو الموقع وتطبيق Native الشقيق.
- الألوان تؤخذ من `artifacts/mobile/constants/tokens.json` المطابق لاستخدام الويب: خمري `#800020`، ذهبي `#D4AF37`، خلفية عاجية `#FAF7F0`، مع أسطح ونصوص الوضع الفاتح/الداكن الموجودة في المصدر.
- الخط Native المعتمد `IBM Plex Sans Arabic`؛ لا يُستبدل بخط جديد. ستُنسخ أصول الشعار من تطبيق Native إلى مساحة التطبيق المستقل، لا تُشارك عبر مسارات خارج Metro.
- تبقى بطاقات لوحة العمل كثيفة وواضحة، مع تنقل هاتف من خمسة عناصر كحد أقصى، واتجاه عربي، ومساحات آمنة ديناميكية.

## خطة التنفيذ المعزول

- Artifact React/Vite مستقل للويب بمقاس هاتف: `artifacts/tabyan-staff-preview`، بعنوان **TABYAN STAFF — معاينة المعلمين والمشرفين**. أُنشئ مسجلّاً في مساحة العمل.
- يقتصر التفاعل على التنقل، التصفية، حالة محلية مؤقتة، ورسائل واضحة بأن الإجراء للمعاينة فقط.
- لا مصادقة إنتاجية، ولا API/tRPC، ولا قاعدة بيانات، ولا WebSocket/اتصال مرئي، ولا دفع إشعارات أو رفع وسائط أو تعديل صلاحيات.
- يبقى تطبيق الطلاب `artifacts/mobile` ومجلدات الموقع والخادم بلا تعديل.
- لا توجد مصادقة أو حواجز دخول؛ صفحة اختيار الدور جزء من المعاينة المحلية فقط.

## تقرير الشاشات النهائي

أُنجزت المعاينة في Artifact الويب المستقل `artifacts/tabyan-staff-preview`، ومسارها `/tabyan-staff-preview/`. تحتوي على بيانات أمثلة محلية، ولا تستخدم مصادقة أو API/tRPC أو قاعدة بيانات أو WebSocket أو تخزيناً دائماً. رسائل التنبيه والنماذج والفلاتر والتبديلات حالات داخل الصفحة فقط.

| المجال | الشاشات المنفذة |
| --- | --- |
| اختيار الدور | صفحة ترحيب واختيار واجهة المعلم أو المشرف |
| المعلم | الرئيسية؛ قائمة الطلاب وبطاقة تفاصيل الطالب؛ الجدول وتفاصيل الحصة؛ التقييمات ونموذج تقييم محلي؛ الإشعارات؛ الإعدادات |
| المشرف | الرئيسية؛ الحسابات وتفاصيل الحساب؛ الجداول؛ مراقبة الحلقات؛ قوائم المراجعة؛ الإشعارات؛ الإعدادات |

تظهر علامة معاينة محلية وإشعار ثابت بأن الأشخاص والسجلات أمثلة وأن التعديلات لا تُرسل ولا تُحفظ. تخفي الواجهة مسارات المصادقة والبث والرفع والإرسال الحقيقي، ولا تعرض أزراراً توحي بتنفيذ تغييرات على حسابات حقيقية. إشعارات المشرف متاحة من رمز الجرس في الترويسة على الهاتف.

### التحقق والقيود

- `pnpm --filter @workspace/tabyan-staff-preview run typecheck` نجح.
- `PORT=3000 BASE_PATH=/tabyan-staff-preview/ pnpm --filter @workspace/tabyan-staff-preview run build` نجح.
- بدأ Workflow المعاينة بنجاح، ورُصدت استجابات 200 لصفحة المعلم والخط والشعار المحليين.
- فُحصت RTL والشاشات الأساسية عند 402 بكسل، وعرضا 320 و1280 بكسل بصور المتصفح. هذه معاينة متصفح وليست اختبار جهاز iPhone أو Android فعلياً.
- البحث في مصدر التطبيق وملف HTML لم يجد استدعاءات API أو fetch/WebSocket أو تخزيناً محلياً دائماً أو روابط موارد خارجية.
- صور الهوية والخطوط المستخدمة محلية، من أصول Tabyan الموجودة، ولم يُنشأ شعار بديل.
- بعد طلب لاحق مستقل، أُزيل زر المصحف ورابطه الخارجي من ترحيب تطبيق الطلاب فقط؛ مسارات التعليم القرآني بقيت كما هي. لم يتغير مصدر بوابات الويب `artifacts/tabyan` أو الخادم `artifacts/api-server`.

## قيد المنصة والقرار المختار

محاولة إنشاء Artifact Expo مستقل باسم `tabyan-staff-preview` رُفضت من المنصة بالرمز `MOBILE_ARTIFACT_LIMIT_REACHED`: هذا المشروع يسمح بتطبيق موبايل واحد فقط، وتطبيق Native الطلاب `artifacts/mobile` موجود بالفعل.

اختار المستخدم معاينة ويب مستقلة بمقاس الهاتف كبديل عن Native في مساحة العمل الحالية. لم أغيّر التطبيق القائم ولم أضف مسارات الموظفين إليه. واجهة الويب الجديدة ليست تطبيق Native، ولن تتصل ببيانات أو خدمات حية.

## الحالة النهائية بعد إنشاء Artifact وتنفيذ المعاينة

- Artifact ويب جديد: أُنشئ باسم `artifacts/tabyan-staff-preview` ومسار معاينة `/tabyan-staff-preview/`.
- واجهات المعاينة: مواءمتها مع بوابتي المعلم والإشراف في الموقع، مع إبقاء البيانات والتفاعلات محلية.
- الفحوص واللقطات: نجح فحص الأنواع والبناء؛ حُدّثت لقطات المسارات الأساسية ولقطات عرض الهاتف وسطح المكتب.
- تطبيق الطلاب: أزيل رابط المصحف الخارجي بطلب لاحق، مع إبقاء مسارات الحفظ والمراجعة والتلاوة والحجوزات. فحص الأنواع واختبارات الترحيب المرتبطة نجحت.
- مصدر بوابات الويب والخادم: لم تتغير ملفاتهما.
