# Quran-MD - Ayah Level

This dataset is part of the complete Quran-MD dataset available here: **[Complete Quran-MD](https://huggingface.co/datasets/Buraaq/quran-audio-text-dataset)**

### Paper

**Quran-MD: A Fine-Grained Multimodal Dataset of the Quran**
(Accepted at: 5th Muslims in ML Workshop co-located with NeurIPS 2025)

📄 **Paper Link:** [quran-md-paper](https://arxiv.org/abs/2601.17880)

### Abstract

> We present Quran-MD, a comprehensive multimodal dataset of the Qur’an that integrates textual, linguistic, and audio dimensions at the verse and word levels. For each verse (ayah), the dataset provides its original Arabic text, English translation, and phonetic transliteration. To capture the rich oral tradition of Qur’anic recitation, we include verse-level audio from 30 distinct reciters, reflecting diverse recitation styles and dialectical nuances. At the word level, each token is paired with its corresponding Arabic script, English translation, transliteration, and an aligned audio recording, allowing fine-grained analysis of pronunciation, phonology, and semantic context. This dataset supports various applications, including natural language processing, speech recognition, text-to-speech synthesis, linguistic analysis, and digital Islamic studies. Bridging text and audio modalities across multiple reciters, this dataset provides a unique resource to advance computational approaches to Qur’anic recitation and study. Beyond enabling tasks such as ASR, tajweed detection, and Qur’anic TTS, it lays the foundation for multimodal embeddings, semantic retrieval, style transfer, and personalized tutoring systems that can support both research and community applications.

## Dataset Description

This dataset contains **187,080 verse-level audio recordings** of the complete Quran with multiple recitations. Each sample includes a complete ayah (verse) recitation along with Arabic text, English translation, and transliteration metadata.

### Dataset Summary

- **🎵 Audio Samples**: 187,080 MP3 files (complete verse recitations)
- **🎤 Reciters**: 30 renowned Quranic reciters
- **📚 Coverage**: Complete Quran (114 surahs, 6,236 unique ayahs)
- **🔢 Reciter Coverage**: Each ayah is recited by all 30 reciters (complete coverage).
- **🌐 Languages**: Arabic (original), English (translation), Transliteration
- **🎧 Audio Quality**: Various bitrates (32kbps to 192kbps)
- **⏱️ Duration**: Approximately 450+ hours of verse-level audio

### Supported Tasks

- **🎙️ Automatic Speech Recognition (ASR)**: Arabic speech recognition training
- **🗣️ Text-to-Speech (TTS)**: Arabic text-to-speech synthesis
- **👤 Speaker Recognition**: Multi-speaker voice identification (30 reciters)
- **📖 Religious Studies**: Quranic recitation research and analysis
- **🎓 Language Learning**: Arabic pronunciation and recitation learning
- **📊 Audio Analysis**: Verse-level prosody and intonation studies

### Languages

- **Arabic** (Classical Arabic - Quranic Arabic)
- **English** (translations)
- **Transliteration** (romanized Arabic)

## Dataset Structure

Each sample contains complete verse-level information:

```python
{
    "surah_id": int32,           # Surah (chapter) number (1-114)
    "ayah_id": int32,            # Ayah (verse) number within surah
    "surah_name_ar": string,     # Surah name in Arabic
    "surah_name_en": string,     # Surah name in English
    "surah_name_tr": string,     # Surah name transliterated
    "ayah_count": int32,         # Total ayahs in this surah
    "ayah_ar": string,           # Complete ayah text in Arabic
    "ayah_en": string,           # Ayah translation in English
    "ayah_tr": string,           # Ayah transliteration
    "reciter_id": string,        # Unique reciter identifier
    "reciter_name": string,      # Reciter's name and audio quality info
    "audio": Audio(),            # Audio file (MP3 format)
}
```

```python
from datasets import load_dataset

# Load the Ayah-level dataset
dataset = load_dataset("Buraaq/quran-md-ayahs")

print(f"Dataset size: {len(dataset):,} ayah recordings")
print(f"Sample keys: {list(dataset[0].keys())}")

# Access first sample
first_sample = dataset[0]
```

```python
import IPython.display as ipd
```

### Filter by Reciter

```python
# Get all recitations by Mishary Alafasy
alafasy_recitations = dataset.filter(lambda x: x["reciter_id"] == "alafasy")
print(f"Alafasy has {len(alafasy_recitations):,} ayah recordings")

# Get unique reciters in dataset
reciters = set(dataset["reciter_id"])
print(f"Available reciters: {len(reciters)}")
for reciter in sorted(reciters):
    count = len(dataset.filter(lambda x: x["reciter_id"] == reciter))

```

### Filter by Surah (Chapter)

```python
# Get all ayahs from Surah Al-Fatiha (Chapter 1) across all reciters

al_fatiha_alafasy = dataset.filter(

```

### Audio Duration Analysis

```python
import librosa

# Analyze audio durations
durations = []
sample_size = 1000  # Analyze first 1000 samples for performance

for i in range(min(sample_size, len(dataset))):
    audio_array = dataset[i]["audio"]["array"]
    sample_rate = dataset[i]["audio"]["sampling_rate"]
    duration = len(audio_array) / sample_rate
    durations.append(duration)

print(f"Average duration: {sum(durations)/len(durations):.2f} seconds")
print(f"Min duration: {min(durations):.2f} seconds")
print(f"Max duration: {max(durations):.2f} seconds")
```
