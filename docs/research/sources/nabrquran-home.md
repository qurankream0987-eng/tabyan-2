## Three correction layers, one structured result

The system separates what was read, how it was pronounced, and whether tajweed rules were applied, so product teams can show focused feedback instead of generic transcripts.

Memorization

### Sequence and reference matching

Detects skipped, added, substituted, or severely misread words by comparing ASR output with the Quranic reference and verse position.

Phonetic

### Letter identity and articulation

Flags substitutions, insertions, and deletions when the recited phoneme changes character identity or articulation, including close makhraj confusions.

Tajweed

### Rule-aware recitation feedback

Monitors rules such as ghunna, qalqala, iqlab, idgham, ikhfaa, tafkheem, tarqeeq, madd, and tadeef with stable error codes.

## A full recitation correction system

Nabr combines a Quran-trained ASR model, reference matching, annotation infrastructure, integration APIs, and conservative arbitration for interactive recitation experiences.

### Quran-trained ASR

A dedicated model trained for recitation rhythm, letters, harakat, waqf, madd, and tajweed properties instead of general Arabic speech.

![Quran-trained ASR: A dedicated model trained for recitation rhythm, letters, harakat, waqf, madd, and tajweed properties instead of general Arabic speech.](https://nabrquran.ai/_next/image?url=%2Fassets%2FQuran-trained-ASR.png&w=3840&q=75)

### Streaming-ready analysis

Supports completed audio and overlapping live windows so apps can provide progressive feedback during recitation.

![Streaming-ready analysis: Supports completed audio and overlapping live windows so apps can provide progressive feedback during recitation.](https://nabrquran.ai/_next/image?url=%2Fassets%2Fstreaming-ready-analysis.png&w=3840&q=75)

### Conservative arbitration

If a word is correctly recognized in a reliable window, Nabr avoids rushing to mark it wrong. Persistent errors are surfaced with the smallest stable set.

![Conservative arbitration: If a word is correctly recognized in a reliable window, Nabr avoids rushing to mark it wrong. Persistent errors are surfaced with the smallest stable set.](https://nabrquran.ai/_next/image?url=%2Fassets%2Fconservative-arbitration.png&w=3840&q=75)
