# Official SDKs

We provide official SDKs to help you integrate the Quran Foundation API into your applications quickly and easily.

## Available SDKs [​](https://api-docs.quran.foundation/docs/sdk/\#available-sdks "Direct link to heading")

| Language | Package | Status |
| --- | --- | --- |
| **JavaScript / TypeScript** | [`@quranjs/api`](https://api-docs.quran.foundation/docs/sdk/javascript/) | Available |
| **Python** | [`quran-foundation-api`](https://api-docs.quran.foundation/docs/sdk/python/) | Available |
| Swift | Coming soon | Planned |
| Kotlin | Coming soon | Planned |

## Get Started [​](https://api-docs.quran.foundation/docs/sdk/\#get-started "Direct link to heading")

Choose your language to get started:

- [JavaScript / TypeScript SDK](https://api-docs.quran.foundation/docs/sdk/javascript/) \- Full-featured SDK for Node.js and browsers
- [Python SDK](https://api-docs.quran.foundation/docs/sdk/python/) \- SDK for server-side Python apps, jobs, scripts, and AI workflows

## Why Use an SDK? [​](https://api-docs.quran.foundation/docs/sdk/\#why-use-an-sdk "Direct link to heading")

Our SDKs provide:

- **Typed clients** \- Type-aware packages where the language ecosystem supports it
- **Authentication helpers** \- OAuth2 and PKCE utilities for server-side integrations
- **Error handling** \- Consistent exceptions and response parsing across supported SDKs
- **Developer experience** \- Familiar package managers, examples, and comprehensive documentation

## Direct API Access [​](https://api-docs.quran.foundation/docs/sdk/\#direct-api-access "Direct link to heading")

If you prefer to use the API directly without an SDK, check out our [Content APIs Quickstart Guide](https://api-docs.quran.foundation/docs/quickstart/) and [API Reference](https://api-docs.quran.foundation/docs/api-reference/).
