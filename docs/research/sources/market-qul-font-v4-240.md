## Using this font

**These steps cover the web only.**
On React Native, Android and iOS you bundle the font with the app instead, using each
platform's own font registration.


Download the font in whichever format suits your platform — **TTF**,
**WOFF** or **WOFF2** — or ship several of them so older browsers
have a fallback. Then declare it with `@font-face` and apply it to your elements.


A font on its own is not enough to render the Quran. Most Quran fonts need a matching
**Quran script**, because the text has to use exactly the characters the font was
built for. Download the matching script from the
[Quran Scripts](https://qul.tarteel.ai/resources/quran-script) page. Fonts for Surah names, Juz
titles and similar decorative text instead rely on **ligatures** — a lookup table
that maps a name to the character that draws it. When this font has one, you will find it in the
Ligatures tab above.

Use the download buttons at the top of this page, then serve the file from your own site or CDN.
