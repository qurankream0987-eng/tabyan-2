# Source capture: Quran.com image generator and source assets

Fetched: 2026-10-15.

URL: https://raw.githubusercontent.com/quran/quran.com-images/master/README.md

The README says the scripts generate Quran page images from old Madani fonts provided by King Fahd Quran Complex, and update glyph bounds so apps can highlight individual words or verses. It distinguishes the code from the assets: “The code is copyleft GPL (read: free) but the actual fonts and pages ... belong to the King Fahd Quran Complex in Saudia Arabia.”

This is repository-owner documentation, not a commercial redistribution grant from the Complex.
